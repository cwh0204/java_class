첫째, 문서 내에서 이동할 위치에 a 태그를 설정하는데 a 태그의 id 속성에 고유한 이름을 지정한다.

























































































top으로 이동 둘째, 링크를 설정할 때 href 속성에 '#id속성값' 형태로 지정한다.
여기서 'id 속성값은 '첫째'에서 설정한 id 속성값들 중 이동할 위치의 값을 말한다.'
