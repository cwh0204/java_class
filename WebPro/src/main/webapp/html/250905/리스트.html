HTML Request(요청) Response(응담)에 대해서 설명하시오.

Request(요청)
사용자가 웹 브라우저에서 주소를 입력하거나 버튼을 클릭하면, 브라우저는 서버에 **요청(Request)**을 보냅니다.
GET POST PUT DELETE
Response(응담)
서버는 요청을 받고, 그에 맞는 응답(Response)**을 브라우저에 돌려줍니다.
200 404 405 500
